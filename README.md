# 🍽️ Cardápio Digital — Bistrô da Lenha

Cardápio digital responsivo desenvolvido com **Next.js, React e TypeScript**, inspirado na experiência de cardápios acessados por QR Code em restaurantes.

O projeto foi desenvolvido inicialmente como parte de um curso de desenvolvimento web e posteriormente personalizado e aprimorado, com foco em componentização, experiência do usuário, responsividade e organização do código.

## 🚀 Demonstração

**Acesse o projeto online:**  
https://cardapio-restaurant-six.vercel.app/

## ✨ Funcionalidades

- 🔎 Busca de pratos pelo nome.
- 🗂️ Filtragem de produtos por categoria.
- 🖼️ Exibição dinâmica dos produtos.
- 📱 Layout responsivo para desktop, tablet e dispositivos móveis.
- 🌙 Alternância entre modo claro e modo escuro.
- 💾 Persistência da preferência de tema utilizando `localStorage`.
- 🎨 Identidade visual personalizada com paleta de cores consistente.
- 🍽️ Banner de apresentação e rodapé temático.
- 🚀 Deploy na Vercel.

## 🛠️ Tecnologias utilizadas

- **Next.js** — framework React.
- **React** — construção de interfaces e componentes.
- **TypeScript** — tipagem estática.
- **CSS Modules** — estilização e organização dos estilos por componente.
- **Git e GitHub** — versionamento e gerenciamento do código.
- **Vercel** — hospedagem e publicação do projeto.

## 📂 Organização do projeto

O projeto utiliza a estrutura do App Router do Next.js, com componentes reutilizáveis, arquivos de dados e estilos organizados por responsabilidade.

- `app/` — páginas e estrutura principal da aplicação.
- `app/componentes/` — componentes reutilizáveis da interface.
- `app/data/` — dados dos produtos.
- `app/servico/` — lógica de filtragem dos produtos, conforme a organização atual do projeto.
- `public/` — imagens e arquivos estáticos.

## 💻 Como executar localmente

### Pré-requisitos

- Node.js instalado.
- npm instalado.

### Instalação

Clone o repositório:

```bash
git clone https://github.com/BrunaP10/cardapio-restaurant.git
```

Entre na pasta do projeto:

```bash
cd cardapio-restaurant
```

Instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Acesse no navegador:

```text
http://localhost:3000
```

Para verificar a compilação de produção:

```bash
npm run build
```
